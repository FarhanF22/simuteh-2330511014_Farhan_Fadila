## Deskripsi
Proyek ini mempelajari tahapan praproses citra menggunakan Python dan OpenCV, termasuk analisis kanal warna, histogram, penapisan, dan evaluasi parameter praproses.

## Struktur Folder
- `notebook/`: notebook untuk eksperimen B1–B5.
- `src/`: kode sumber dan fungsi praproses.
- `data/`: dataset yang digunakan.
- `hasil/`: hasil eksperimen dalam bentuk CSV, JSON, dan artefak lainnya.
- `Laporan/`: dokumen presentasi dan laporan proyek.
- `requirements.txt`: daftar dependensi Python.

## Persiapan Lingkungan
Pastikan Python sudah terpasang. Buat virtual environment dan pasang dependensi:

```bash
python -m venv .venv
```

Pada Windows:

```bash
.venv\Scripts\activate
```

Pasang dependensi:

```bash
python -m pip install -r requirements.txt
```

## Cara Menjalankan
1. Buka folder proyek di VS Code atau Jupyter.
2. Pilih kernel Python dari virtual environment.
3. Jalankan notebook di folder `notebook/` secara berurutan dari B1 sampai B5.
4. Periksa hasil eksperimen di folder `hasil/`.

## Konfigurasi Praproses
Konfigurasi akhir mengacu pada `hasil/param_praproses.json`. Pastikan nilainya sesuai dengan konfigurasi yang digunakan dalam laporan dan presentasi.

## Hasil dan Evaluasi
Hasil eksperimen disimpan dalam CSV dan JSON di folder `hasil/`. Angka pada laporan dan presentasi harus mengacu pada hasil eksperimen yang sudah diverifikasi.
